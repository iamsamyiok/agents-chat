Agents Chat Portable（Agents 群聊）Windows 版
================================================

一、这是什么
-----------
一个免安装的多智能体群聊工具：
- 自动识别你电脑上已安装的执行内核（四选一，装任意一个即可）：
    OpenCode     npm install -g opencode-ai（多 Provider，默认首选）
    Claude Code  npm install -g @anthropic-ai/claude-code（Anthropic）
    Codex CLI    npm install -g @openai/codex（OpenAI，自带沙箱）
    pi           npm install -g @earendil-works/pi-coding-agent（多 Provider）
  内核具备读写文件、执行命令、联网检索等真实能力；
  「⚙ 智能体配置」顶部下拉框可切换内核（默认「自动」按上面顺序选择）
- 内置 3 个智能体（可多开可自定义）：工程师 / 研究员 / 文案，
  每个实例可以有不同的角色人设
- 微信风格群聊界面，@智能体 点名对话
- 任务队列：顺序任务 + 定时任务，逐个执行，
  各任务之间上下文完全独立（每次执行都是全新会话）
- 真实反馈：执行过程中的每一次工具调用（读文件、跑命令等）都会
  实时显示在聊天流里；失败会明确标红报错，绝不假装完成

二、前置要求（必读）
--------------------
1. 本机已安装任一执行内核（四选一），cmd 里能跑通对应命令：
        opencode --version
        claude --version
        codex --version
        pi --version
2. 该内核里已配置好模型与登录（各内核自己的登录命令，如
   opencode auth login / claude 按提示登录 / codex login / pi 内 /login）。
   模型与密钥由内核自己管理，本程序不做任何 API 配置。

三、快速开始
-----------
1. 解压 zip 到任意目录（路径不要含特殊字符）
2. 双击 start.bat，浏览器自动打开 http://localhost:3456
3. 右上角显示绿色内核名称（如「OpenCode」）= 一切正常；
   红色「未检测到内核」= 先完成上面第二节
4. 左上角「导入」粘贴任务清单，或直接在聊天框对话

四、可选配置（.env 文件）
------------------------
一般不需要改，全部有默认值：

  AGENTS_CHAT_MODEL=              指定模型（provider/model 格式），
                                  留空用所选内核的默认模型
  AGENTS_CHAT_AUTO_APPROVE=1      自动批准权限请求（无人值守执行需要，
                                  仅 OpenCode 内核）
  AGENTS_CHAT_TIMEOUT_MS=600000   单任务超时（毫秒）
  AGENTS_CHAT_OPENCODE_CMD=       手动指定 opencode 完整路径
  AGENTS_CHAT_CLAUDE_CMD=         手动指定 claude 完整路径
  AGENTS_CHAT_CODEX_CMD=          手动指定 codex 完整路径
  AGENTS_CHAT_PI_CMD=             手动指定 pi 完整路径
  AGENTS_CHAT_HANDOFF=doc         智能体交接模式：doc=结构化交接
                                  文档（默认，省 token）；full=旧模式
                                  （前序产出全文截断拼接）
  AGENTS_CHAT_VERIFY_CMD=         自定义验证命令（如 npm test）：每轮
                                  验收前自动在统一工作目录执行，退出码
                                  非零会作为客观事实交给管家裁决
  AGENTS_CHAT_AUTOVERIFY=1        0=关闭验收前的自动核查
                                  （文件存在性/JS 语法/JSON 校验/占位符）
  AGENTS_CHAT_ROUNDTABLE_ROUNDS=2 圆桌讨论最大轮数（每轮每人发言一次，
                                  主持人可在收敛后提前结束）
  AGENTS_CHAT_MOCK=0              1=演示模式（模拟输出，界面体验用）

  —— 管家记忆（v3.10.0 新增）——
  AGENTS_CHAT_AUX_BASE_URL=       辅助小模型接口（OpenAI 兼容，如
                                  https://api.siliconflow.cn/v1），
                                  用于记忆整理与长对话压缩；
                                  免费小模型即可（如 Qwen/Qwen3-8B）
  AGENTS_CHAT_AUX_MODEL=          模型名（如 Qwen/Qwen3-8B）
  AGENTS_CHAT_AUX_API_KEY=        接口密钥（只写在本文件，不会上传）
  AGENTS_CHAT_MEMORY=1            0=关闭管家长期记忆
  说明：不配置辅助小模型时记忆照常工作（写满自动淘汰最旧条目），
  仅跳过需要模型参与的记忆提炼与合并压缩

五、界面使用
-----------
【聊天】
  - 输入框直接说话 → 由「管家」理解需求、调度子智能体完成
  - @工程师 你好 → 点名某个智能体
  - @工程师 @研究员 做个调研 → 多个智能体流水线依次执行
  - 「💬 圆桌」按钮开启后发送 → 圆桌讨论：被 @ 者上桌（不 @ 则
     全体），成员轮流发言、可见彼此观点并反驳；管家当主持人，
     每轮判定收敛/继续（继续时给聚焦问题），结束后总结共识/
     分歧/建议行动；最多 2 轮、每次发言 600 字内（见第四节可调）
     每轮每人的发言独立成条、默认折叠约三行（点「展开全文」查看），
     只有管家最终总结完整展示
  - 管家调度：规划 → 派发执行（阶段内并行/阶段间串行）→ 自动核查
    （文件/语法/JSON/占位符/自定义验证命令，客观事实而非自述）→ 验收
    （不合格打回重做）→ 汇总交付
  - 汇总包含简明结果概要；有成果文件时在末尾列出每个文件的
    完整绝对路径（智能体在工作目录中真实创建的文件）
  - 子智能体过程内容默认折叠（约三行），点「展开全文」查看
  - 每个智能体执行时显示「正在执行…」动画条
  - 智能体之间以结构化交接文档传递工作（任务/进度/产出摘要/
    成果文件位置/给下游的建议），下游先读交接文档与成果文件
    全文再开工；交接过程可在「🔭 智能体流转」视图中追溯
  - [工具] read（文件路径）执行完成 = 真实工具调用（含操作对象）
  - 处理中「发送」按钮变红色「停止」，点击可随时中止当前编排
  - 每条正式产出下方显示「📄 过程存档」路径：该阶段完整输出
    的系统存档（供核验与内部交接）；最终成果文件以管家交付
    清单里的完整路径为准
  - 任务批量执行期间仍可正常聊天，两边互不阻塞

【任务栏（左侧）— 顺序/定时同一位置切换】
  - 任务栏顶部开关：「📋 顺序任务」/「⏰ 定时任务」两个标签页
    在同一位置切换显示，底部按钮随视图变化：
  - 顺序视图：底部为「按顺序执行全部待办」（执行中变红色
    「停止执行」）；单个任务可点「执行」，列表可拖拽调序
  - 定时视图：底部为「▶ 启动定时任务 / ⏸ 关闭定时任务」总开关
    （关闭后到点不再自动执行）；列表显示启动时间与倒计时，
    支持「立即执行」「重跑」「删除」
  - 顺序任务：「导入任务」→「顺序任务」，每行 1. 2. 3. 编号，
    行末可 @智能体 指派（@管家=调度多智能体，@子智能体=独立完成）
  - 任务互不干扰：每个任务都是独立会话，上下文不互通
  - 状态：灰=待执行，蓝=执行中，绿=完成，红=失败（点开可看报错）
  - 定时任务：「导入任务」→「定时任务」，行首写启动时间（格式
    20260818-1307），行首输入 [] 自动填入当前时间；到点自动执行
    （需程序保持运行），触发后点击条目可查看其会话
  - 完成提醒：任务完成时右下角弹窗显示最终回答部分内容，点击
    跳回原会话；不管它则 3 秒后自动消失，会话条目左侧留绿点
    （未读）；执行中显示「执行中」运转标识，空闲且无未读无标识

【智能体配置（⚙）】
  - 执行内核：配置页顶部下拉框，自动识别 OpenCode / Claude Code /
    Codex / pi，已安装的标 ✓ 可选，未安装的灰显
  - 管家记忆（💾）：管家跨会话记住两类信息 —— 工作笔记（项目
    事实/环境约定/教训）与用户画像（偏好/习惯）。规划、验收与
    圆桌讨论时自动参考；任务完成后由辅助小模型自动提炼沉淀
    （聊天区提示「💾 管家记忆已更新」）；配置页可查看/手动编辑
    （一行一条）。两仓各有字数上限（2000/1200 字）：写满时自动
    让辅助小模型合并压缩，失败则淘汰最旧条目，绝不报错卡流程；
    规划前还会按关键词检索历史消息，把「以前聊过的相关内容」
    作为背景注入。AGENTS_CHAT_MEMORY=0 可整体关闭
  - 团队仓库（📦）：内置经典团队一键应用 —— 软件开发团队
    （产品经理/架构师/工程师/测试工程师，源自 MetaGPT 虚拟软件
    公司）、内容创作团队（研究员/作家/编辑）、深度调研团队
    （研究员/分析师）、翻译校对团队（翻译员/审校员）；
    可「替换」当前名单或「追加」，保存后生效
  - 每个智能体可选职业图标，聊天头像/成员栏/补全菜单统一显示
  - 工作目录（可选）：指定一个本机文件夹，所有智能体的工作
    记录与产出文件都保存在其中；不设置则用程序默认目录
    （不是上传文件，只需填写文件夹完整路径）
  - 智能体名片：每个智能体可「名片」导出 JSON 文件分享给别人；
    「📥 导入名片」粘贴或选文件即可加入（只含角色定义，
    不含内核与密钥，接收方用自己的内核运行）

【流转视图（🔭 智能体流转按钮）】
  - 智能体协作可视化：每个智能体一条泳道，展示派发、执行、
    交接、返工、验收全过程
  - 绿色块=完成，红色块=失败，虚线动画=执行中；
    蓝色曲线=交接（产出交给下游），橙色曲线=返工
  - 点击块/连线/圆点查看详情（指令、交接说明、成果文件路径）
  - 断点重跑：详情面板点「↻ 从阶段 N 重跑」，该阶段起重新执行与
    验收，之前阶段的产出自动复用（某环节翻车不用整轮重来）；
    重跑过程回到原会话实时展示
  - 顶部下拉切换历史编排记录，可自动刷新观察进行中的任务

【稳定性说明】
  - 程序启动/退出时自动把「执行中」的任务复位为「待执行」，
    异常关机不会留下永远卡住的任务
  - 同一批任务不会被重复启动（防双击/防并发重复执行）
  - 若浏览器提示「与服务连接中断」，任务可能仍在后台执行，
    刷新页面即可看到最新进度

六、常用问题
-----------
Q: 换端口？
A: 编辑 start.bat，把 set PORT=3456 改成别的

Q: 怎么加/改智能体？
A: 网页右上角「⚙ 智能体配置」：名称（@点名用）、职业图标、
   技能说明（管家调度参考）、自定义提示词。统一工作目录在配置页
   顶部设置，所有智能体共用。

Q: 任务失败显示超时？
A: 在 .env 里调大 AGENTS_CHAT_TIMEOUT_MS（默认 10 分钟）

Q: 数据在哪？怎么清空？
A: 全部在 .data/ 目录（聊天记录、任务、配置、管家记忆 .data/memory.json）。
   网页里有「清空」按钮；删除 .data/ 目录 = 恢复出厂

Q: 双击 start.bat 闪退？
A: 打开 cmd，cd 进目录手动运行 bin\node.exe app\server.js 看报错；
   .data/server.log 里也有完整日志

七、目录说明
-----------
  .env            可选行为配置（见第四节）
  start.bat       双击启动
  bin/node.exe    内置 Node 22 运行时（跑本程序自身，免安装）
  app/            应用代码（零依赖）
  .data/          运行数据（可随时清空）
  .data/outputs/  每次对话/任务中各智能体的完整产出归档
                  （按会话分目录，串行交接时后续智能体直接读取完整文件，
                  界面消息下方的「📄 路径」即指向这里）
