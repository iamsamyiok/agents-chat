Agents Chat Portable（Agents 群聊）Windows 版
================================================

一、这是什么
-----------
一个免安装的多智能体群聊工具：
- 复用你电脑上已安装的 OpenCode（opencode 命令）作为统一内核，
  具备读写文件、执行命令、联网检索等真实能力
- 内置 3 个智能体（可多开可自定义）：规划师 / 工程师 / 研究员，
  每个实例可以有不同的角色人设
- 微信风格群聊界面，@智能体ID 点名对话
- 任务队列：粘贴任务清单自动提取，按时间先后排序，逐个执行，
  各任务之间上下文完全独立（每次执行都是全新会话）
- 真实反馈：执行过程中的每一次工具调用（读文件、跑命令等）都会
  实时显示在聊天流里；失败会明确标红报错，绝不假装完成

二、前置要求（必读）
--------------------
1. 本机已安装 OpenCode，cmd 里能跑通：
       opencode --version
   未安装的话先安装：
       npm install -g opencode-ai
2. OpenCode 里已配置好模型（终端运行 opencode auth login，
   按提示选择服务商并登录）。模型与密钥由 OpenCode 自己管理，
   本程序不做任何 API 配置。

三、快速开始
-----------
1. 解压 zip 到任意目录（路径不要含特殊字符）
2. 双击 start.bat，浏览器自动打开 http://localhost:3456
3. 右上角显示绿色「OpenCode 内核」= 一切正常；
   红色「未检测到 OpenCode」= 先完成上面第二节
4. 左上角「导入」粘贴任务清单，或直接在聊天框对话

四、可选配置（.env 文件）
------------------------
一般不需要改，全部有默认值：

  AGENTS_CHAT_MODEL=              指定模型（provider/model 格式），
                                  留空用 OpenCode 默认模型
  AGENTS_CHAT_AUTO_APPROVE=1      自动批准权限请求（无人值守执行需要）
  AGENTS_CHAT_TIMEOUT_MS=600000   单任务超时（毫秒）
  AGENTS_CHAT_OPENCODE_CMD=       手动指定 opencode 完整路径
  AGENTS_CHAT_MOCK=0              1=演示模式（模拟输出，界面体验用）

五、界面使用
-----------
【聊天】
  - 输入框直接说话 → 默认发给默认智能体（规划师）
  - @oc-2 你好 → 点名某个智能体
  - @oc-1 @oc-2 做个功能 → 多个智能体流水线依次执行
  - 编排模式选「主智能体」→ 规划 → 派发执行 → 验收，
    不合格打回重做（带反馈改进），合格后汇总报告
  - 灰色小条 = 阶段提示；[工具] xxx 执行完成 = 真实工具调用过程

【任务队列（左侧）】
  - 点「导入」，粘贴任务清单，每行一个任务
  - 支持的写法（时间自动用于排序，晚的排后面）：
      09:00 检查邮件
      2026-08-17 14:30 交付报告
      - 联系供应商（无时间，排在当天带时间任务之后）
      1. 修复登录 bug
      [ ] 整理桌面
  - 点单个任务的「执行」按钮跑一个；点底部绿色按钮按时间顺序跑全部待办
  - 任务互不干扰：每个任务都是独立会话，上下文不互通
  - 状态：灰=待执行，蓝=执行中，绿=完成，红=失败（点开可看报错）

六、常用问题
-----------
Q: 换端口？
A: 编辑 start.bat，把 set PORT=3456 改成别的

Q: 怎么加/改智能体？
A: 编辑 .data/config.json 里的 agents 数组，
   每个智能体可设 name（名字）、systemPrompt（人设）、model（模型）。
   model 留空 = 用默认模型；填 provider/model（如 openai/gpt-4o）单独指定

Q: 任务失败显示超时？
A: 在 .env 里调大 AGENTS_CHAT_TIMEOUT_MS（默认 10 分钟）

Q: 数据在哪？怎么清空？
A: 全部在 .data/ 目录（聊天记录、任务、配置）。
   网页里有「清空」按钮；删除 .data/ 目录 = 恢复出厂

Q: 双击 start.bat 闪退？
A: 打开 cmd，cd 进目录手动运行 bin\node.exe app\server.js 看报错；
   .data/server.log 里也有完整日志

七、目录说明
-----------
  .env            可选行为配置（见第四节）
  start.bat       双击启动
  bin/node.exe    内置 Node 22 运行时（跑本程序自身，免安装）
  app/            应用代码（零依赖）
  .data/          运行数据（可随时清空）
