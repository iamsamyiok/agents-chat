智能体配置

每个智能体都是一个独立的 AI Agent：执行内核由顶部下拉框统一选择（OpenCode / Claude Code / Codex / pi），图标用于辨认，名称用于 @ 点名，技能说明供管家调度参考，自定义提示词会在任务下发时附加在用户提示词前面。所有智能体使用所选内核的默认模型。「管家」为内置调度智能体，不可修改。
🧠 执行内核（所有智能体共用）
🤖 默认模型（LLM）
AI 组队、AI 编排与未单独指定模型的任务都用这里的默认模型执行；单聊工作台与单张任务卡可在各自界面临时改用其他模型。列表来自 opencode models，也可直接输入 provider/model；留空 = 用内核默认。保存即写入 OpenCode 全局配置。
🔌 自定义 LLM 接入（自带 API）
自带 OpenAI 兼容端点：填好 Base URL / API Key / 模型名即注册为「自定义接入」，并自动设为全局默认模型——AI 组队、AI 编排、多任务编排全部直接走它，无需在内核里另配 provider。API Key 只存本机 OpenCode 配置文件，界面永不回显明文。
📁 产出存档目录（可选）
智能体工作中产生的文档与成果文件都存档到这个本机文件夹（填写文件夹完整路径即可，会自动创建）。可不设置（留空则用程序默认目录）。
💾 管家记忆
管家跨会话记住工作笔记与你的偏好，规划时自动参考、任务完成后自动沉淀。点此查看或手动编辑。
🧹 数据维护
任务、消息、会话、产出文件与流转日志等工作数据超过 15 天会自动清理（.env 中 AGENTS_CHAT_PRUNE_DAYS 可调整天数）；管家记忆与配置永久保留。也可立即手动清理：
🛂 人工审批关卡
开启后编排会在关键节点暂停，等你点「同意」才继续（聊天与定时任务都生效）；超时 10 分钟未处理视为否决。

🧑‍💼 分工职工配置

分工模式专属职工库（与群聊/单聊智能体相互独立）：每名职工一个专门职业（财务、销售、研发、文案、调研员、程序员、架构师…），职责单一互补。聊天页右上角「参与职工」决定每轮由谁参与分工；消息中 @ 职工可点名协作。

➕ 新增 / 编辑职工

🪄 AI 生成职工

描述你要办的事，AI 组建顾问生成一组专职职工（生成后可逐个入库修改）。

📦 团队仓库

取材自开源社区验证过的经典多智能体组合。选择一套应用：「替换」换掉当前全部子智能体，「追加」在现有名单后加入（重名自动加序号）。应用后仍可自由增删改，点配置页「保存」才生效。

🪄 AI 组队

用一句话描述你的需求，AI 扮演团队设计师，生成一套分工明确的智能体团队（名称/图标/技能说明/提示词）。先预览再应用，应用后仍可自由增删改，点配置页「保存」才生效。

聊天历史（主会话）

按时间正序展示全部主会话记录（含已开启新会话前的内容），仅供查阅；消息中的 .md 文件路径可点击预览

💾 管家记忆

管家跨会话记住的工作笔记与用户偏好：规划时自动参考，任务完成后自动提炼沉淀。一行一条，可手动增删改；两仓各有字数上限（笔记 2000 字 / 画像 1200 字），写满后系统自动让辅助小模型合并压缩，失败则淘汰最旧条目，绝不丢失新增内容。
