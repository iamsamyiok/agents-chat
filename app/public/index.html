智能体配置

每个智能体都是一个独立的 AI Agent：执行内核由顶部下拉框统一选择（OpenCode / Claude Code / Codex / pi），图标用于辨认，名称用于 @ 点名，技能说明供管家调度参考，自定义提示词会在任务下发时附加在用户提示词前面。所有智能体使用所选内核的默认模型。「管家」为内置调度智能体，不可修改。
🧠 执行内核（所有智能体共用）
📁 工作目录（可选）
不是上传文件：这里指定一个本机文件夹，所有智能体的工作记录与产出文件都会保存在其中。可不设置（留空则用程序默认目录）。
💾 管家记忆
管家跨会话记住工作笔记与你的偏好，规划时自动参考、任务完成后自动沉淀。点此查看或手动编辑。
🛂 人工审批关卡
开启后编排会在关键节点暂停，等你点「同意」才继续（聊天与定时任务都生效）；超时 10 分钟未处理视为否决。

导入智能体名片

粘贴名片 JSON，或选择名片文件（其他 Agents Chat 导出的 .json）。导入后先加入下方列表，点「保存」才生效。

📦 团队仓库

取材自开源社区验证过的经典多智能体组合。选择一套应用：「替换」换掉当前全部子智能体，「追加」在现有名单后加入（重名自动加序号）。应用后仍可自由增删改，点配置页「保存」才生效。

聊天历史（主会话）

按时间正序展示全部主会话记录（含已开启新会话前的内容），仅供查阅；消息中的 .md 文件路径可点击预览

💾 管家记忆

管家跨会话记住的工作笔记与用户偏好：规划时自动参考，任务完成后自动提炼沉淀。一行一条，可手动增删改；两仓各有字数上限（笔记 2000 字 / 画像 1200 字），写满后系统自动让辅助小模型合并压缩，失败则淘汰最旧条目，绝不丢失新增内容。
工作笔记（项目事实 / 环境约定 / 教训）
用户画像（偏好 / 习惯 / 身份）
